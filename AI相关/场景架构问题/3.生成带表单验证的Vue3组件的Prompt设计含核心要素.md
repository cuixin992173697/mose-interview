## 生成带表单验证的 Vue3 组件的 Prompt 设计含核心要素

### 1. 为什么需要专门设计 Prompt

让 LLM 一次生成"可直接用"的 Vue3 表单组件，必须在 Prompt 里把技术栈、结构、验证规则、错误提示、UI 库等约束讲清，否则生成物常是"能跑但不符合项目规范"的半成品。

### 2. Prompt 核心要素

| 要素 | 内容 | 作用 |
| --- | --- | --- |
| 技术栈约束 | Vue3 + Composition API + `<script setup>` + TypeScript | 锁定写法 |
| 组件结构 | props / emits / defineModel / 暴露方法 | 规范组件契约 |
| 表单字段定义 | 字段名/类型/默认值/标签 | 明确建模 |
| 验证规则 | 必填 / 格式（邮箱手机）/ 长度 / 自定义校验 | 验证逻辑 |
| 错误提示 | 规则未通过的提示文案 + 展示位置 | UX |
| UI 库 | Element Plus / Naive UI / Ant Design Vue | 复用现成组件 |
| 可访问性 | label 关联、aria、键盘 | a11y |
| 输出格式 | 单文件组件 .vue 完整代码 + 用法示例 | 可直接落地 |

### 3. 完整 Prompt 模板

```text
你是一名资深 Vue3 工程师。请生成一个带表单验证的 Vue3 组件，要求如下：

【技术栈】Vue3 + Composition API + <script setup> + TypeScript + Element Plus
【组件名】UserForm.vue，用于用户注册表单
【字段】
- username: string，必填，3~16 位
- email: string，必填，合法邮箱
- phone: string，选填，合法手机号
- password: string，必填，8~20 位含字母数字
【验证规则】
- 每个字段定义 Element Plus 的 rules
- 邮箱用正则校验
- 手机号用正则校验
- 密码含强度校验
【交互】
- 提交时整体验证，不通过则展示错误
- emits('submit', formData) 与 emits('cancel')
- 暴露 validate() / resetFields() 方法（defineExpose）
【UI】
- 使用 Element Plus 的 el-form / el-form-item / el-input / el-button
- 错误提示由 form 自带
- 响应式布局
【可访问性】label 关联输入框
【输出】完整 UserForm.vue 代码 + 父组件用法示例
```

### 4. 生成组件代码示例

```vue
<script setup lang="ts">
import { reactive, ref } from 'vue'
import type { FormInstance, FormRules } from 'element-plus'

const emit = defineEmits<{
  (e: 'submit', data: UserForm): void
  (e: 'cancel'): void
}>()

interface UserForm {
  username: string
  email: string
  phone: string
  password: string
}

const formRef = ref<FormInstance>()
const form = reactive<UserForm>({
  username: '', email: '', phone: '', password: '',
})

const rules: FormRules<UserForm> = {
  username: [
    { required: true, message: '请输入用户名', trigger: 'blur' },
    { min: 3, max: 16, message: '3~16 位', trigger: 'blur' },
  ],
  email: [
    { required: true, message: '请输入邮箱', trigger: 'blur' },
    { pattern: /^[\w.+-]+@[\w-]+\.[\w.-]+$/, message: '邮箱格式错误', trigger: 'blur' },
  ],
  phone: [
    { pattern: /^1[3-9]\d{9}$/, message: '手机号格式错误', trigger: 'blur' },
  ],
  password: [
    { required: true, message: '请输入密码', trigger: 'blur' },
    { pattern: /^(?=.*[A-Za-z])(?=.*\d).{8,20}$/, message: '8~20 位含字母数字', trigger: 'blur' },
  ],
}

const onSubmit = async () => {
  if (!formRef.value) return
  await formRef.value.validate((valid) => {
    if (valid) emit('submit', { ...form })
  })
}
const reset = () => formRef.value?.resetFields()

defineExpose({ validate: () => formRef.value?.validate(), resetFields: reset })
</script>

<template>
  <el-form ref="formRef" :model="form" :rules="rules" label-width="80px">
    <el-form-item label="用户名" prop="username">
      <el-input v-model="form.username" />
    </el-form-item>
    <el-form-item label="邮箱" prop="email">
      <el-input v-model="form.email" />
    </el-form-item>
    <el-form-item label="手机号" prop="phone">
      <el-input v-model="form.phone" />
    </el-form-item>
    <el-form-item label="密码" prop="password">
      <el-input v-model="form.password" type="password" show-password />
    </el-form-item>
    <el-form-item>
      <el-button type="primary" @click="onSubmit">提交</el-button>
      <el-button @click="reset">重置</el-button>
    </el-form-item>
  </el-form>
</template>
```

### 5. 一句话总结

生成 Vue3 表单组件的 Prompt 核心要素 = **技术栈约束 + 组件结构契约 + 字段建模 + 验证规则 + 错误提示 + UI 库 + 可访问性 + 输出格式**，把项目规范写进 Prompt，LLM 才能一次产出可直接落地的 `<script setup>` + TS + Element Plus 表单组件。
