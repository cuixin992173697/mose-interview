## 生成带数据验证、错误提示的 React 表单组件的 Prompt 设计含上下文约束

### 1. React 表单 Prompt 的关键：上下文约束

React 生态表单方案多（react-hook-form / formik / 自建），LLM 若不知道项目用哪套，生成的代码大概率用不上。上下文约束 = 把"项目既有技术栈、代码风格、库选型"明确告诉 LLM，让生成物贴合项目。

### 2. 上下文约束要素

| 约束 | 内容 | 作用 |
| --- | --- | --- |
| 技术栈 | React 18 + TypeScript | 基础 |
| 表单库 | react-hook-form（推荐） | 状态与提交管理 |
| 验证库 | zod / yup（zod + TS 更佳） | schema 验证 |
| UI 库 | Ant Design / MUI / shadcn | 复用组件 |
| 状态管理 | 表单内库管 / 全局 store | 明确边界 |
| 错误展示 | 字段下红字 / Toast / 表单顶部 | 规范 UX |
| 既有代码风格 | 函数组件 / 命名导出 / 路径别名 | 贴合项目 |
| 输出 | 单组件 + schema + 用法示例 | 可落地 |

### 3. 含上下文约束的完整 Prompt 模板

```text
你是资深 React 工程师。基于以下项目上下文，生成一个带数据验证与错误提示的表单组件。

【项目上下文】
- React 18 + TypeScript + Vite
- 表单库：react-hook-form
- 验证库：zod + @hookform/resolvers
- UI 库：Ant Design 5
- 代码风格：函数组件、命名导出、路径别名 @/ 指向 src/
- 错误展示：字段下方红色提示

【需求】生成 RegisterForm 组件
【字段】
- username: 必填，3~16 位
- email: 必填，合法邮箱
- password: 必填，8~20 位含字母数字
- confirm: 必填，须与 password 一致
【验证】用 zod schema，confirm 用 refine 校验一致性
【交互】
- 提交校验不通过展示错误
- 暴露 onSubmit(data)
- loading 态
【输出】
1. schema 定义（zod）
2. RegisterForm.tsx 完整代码（命名导出）
3. 父组件用法示例
```

### 4. 生成组件代码示例

```ts
// schema.ts
import { z } from 'zod'

export const registerSchema = z.object({
  username: z.string().min(3).max(16, '3~16 位'),
  email: z.string().email('邮箱格式错误'),
  password: z.string().regex(/^(?=.*[A-Za-z])(?=.*\d).{8,20}$/, '8~20 位含字母数字'),
  confirm: z.string(),
}).refine((d) => d.password === d.confirm, {
  path: ['confirm'], message: '两次密码不一致',
})
export type RegisterFormValues = z.infer<typeof registerSchema>
```

```tsx
// RegisterForm.tsx
import { useForm } from 'react-hook-form'
import { zodResolver } from '@hookform/resolvers/zod'
import { Form, Input, Button } from 'antd'
import { registerSchema, type RegisterFormValues } from '@/schema'

export function RegisterForm({ onSubmit }: { onSubmit: (d: RegisterFormValues) => void }) {
  const { register, handleSubmit, formState: { errors, isSubmitting } } =
    useForm<RegisterFormValues>({ resolver: zodResolver(registerSchema) })

  return (
    <Form layout="vertical" onFinish={handleSubmit(onSubmit)}>
      <Form.Item label="用户名" validateStatus={errors.username ? 'error' : ''} help={errors.username?.message}>
        <Input {...register('username')} />
      </Form.Item>
      <Form.Item label="邮箱" validateStatus={errors.email ? 'error' : ''} help={errors.email?.message}>
        <Input {...register('email')} />
      </Form.Item>
      <Form.Item label="密码" validateStatus={errors.password ? 'error' : ''} help={errors.password?.message}>
        <Input.Password {...register('password')} />
      </Form.Item>
      <Form.Item label="确认密码" validateStatus={errors.confirm ? 'error' : ''} help={errors.confirm?.message}>
        <Input.Password {...register('confirm')} />
      </Form.Item>
      <Button type="primary" htmlType="submit" loading={isSubmitting}>注册</Button>
    </Form>
  )
}
```

Vue3 版的对照设计见 [[3.生成带表单验证的Vue3组件的Prompt设计含核心要素]]。

### 5. 一句话总结

React 表单 Prompt 的关键是**上下文约束**——明确 react-hook-form + zod + UI 库 + 代码风格，让 LLM 生成贴合项目的组件；用 zod schema 做验证（含 refine 一致性校验）、字段下红字展示错误，一次产出可落地代码。
