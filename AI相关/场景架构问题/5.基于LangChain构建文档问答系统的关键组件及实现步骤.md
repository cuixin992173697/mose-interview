## 基于 LangChain 构建文档问答系统的关键组件及实现步骤

### 1. 关键组件

| 组件 | 作用 | 典型实现 |
| --- | --- | --- |
| DocumentLoader | 加载文档（PDF/Word/MD/网页） | PyMuPDFLoader / UnstructuredPDFLoader |
| TextSplitter | 切片 | RecursiveCharacterTextSplitter |
| Embeddings | 向量化 | OpenAIEmbeddings / bge |
| VectorStore | 向量存储与检索 | FAISS / Chroma / Milvus |
| Retriever | 检索接口 | as_retriever / EnsembleRetriever |
| LLM | 生成回答 | ChatOpenAI 等 |
| Chain / LCEL | 串联检索+生成 | RetrievalQA / LCEL Runnable |

> 组件详解见 agent 目录的《2.LangChain的核心组件详解》《3.LangChain的核心架构解析》。

### 2. 实现步骤

| 步骤 | 要点 |
| --- | --- |
| ① 加载 | 选对 loader，PDF 注意表格/扫描 |
| ② 切片 | chunk_size 256~512、overlap 10%~20%，优先按结构切 |
| ③ 向量化 | 选合适 embedding 模型，中文用 bge |
| ④ 入库 | 存向量库 + 元数据，建索引 |
| ⑤ 检索 | similarity_search 或 retriever，top-k |
| ⑥ 生成 | 检索片段 + 问题 → LLM 生成带引用答案 |

> 完整 RAG 流程见 rag 目录的《04.详解RAG的完整工作流程》《41.RAG的定义及基于LangChain的RAG应用实现》。

### 3. 完整代码示例

```python
from langchain_community.document_loaders import PyMuPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain_community.vectorstores import FAISS
from langchain.chains import RetrievalQA

# ① 加载
docs = PyMuPDFLoader("report.pdf").load()

# ② 切片
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_documents(docs)

# ③④ 向量化 + 入库
embeddings = OpenAIEmbeddings()
vectorstore = FAISS.from_documents(chunks, embeddings)
retriever = vectorstore.as_retriever(search_kwargs={"k": 4})

# ⑤⑥ 检索 + 生成
llm = ChatOpenAI(model="gpt-4o", temperature=0)
qa = RetrievalQA.from_chain_type(
    llm=llm, retriever=retriever, return_source_documents=True,
)
result = qa.invoke({"query": "文档的核心结论是什么？"})
print(result["result"])
for doc in result["source_documents"]:
    print(doc.metadata)  # 溯源
```

### 4. 进阶优化

| 方向 | 做法 |
| --- | --- |
| 混合检索 | EnsembleRetriever 组合向量 + BM25 |
| Rerank | 接 Cross-Encoder 精排 |
| 多轮记忆 | ConversationalRetrievalChain / history |
| 溯源引用 | return_source_documents + 元数据标注 |
| 流式输出 | LCEL Runnable + stream |

### 5. 一句话总结

基于 LangChain 构建文档问答 = **Loader 加载 → Splitter 切片 → Embeddings 向量化 → VectorStore 入库 → Retriever 检索 → LLM 生成**六步，用 RetrievalQA 或 LCEL 串联；进阶叠加混合检索、Rerank、记忆与溯源，即可从 Demo 走向生产。
