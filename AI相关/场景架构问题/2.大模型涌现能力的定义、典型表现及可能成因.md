## 大模型涌现能力的定义、典型表现及可能成因

### 1. 什么是涌现能力

涌现能力 = 模型规模（参数量/数据/算力）增长到某一阈值后，**突然出现**的能力——小模型完全不具备、大模型突然会了，且能力提升与规模呈非线性跳变。

| 维度 | 说明 |
| --- | --- |
| 定义 | 规模突破阈值后突现的、小模型没有的能力 |
| 特征 | 非线性、突变（相变式）、不可外推 |
| 触发因素 | 参数量、训练数据量、训练算力 |
| 经典来源 | 2022 Wei et al.《Emergent Abilities of LLMs》 |

### 2. 典型表现

| 涌现能力 | 表现 | 触发规模量级（大致） |
| --- | --- | --- |
| 少样本学习（In-context Learning） | 不微调，靠 few-shot 示例学会新任务 | 数十亿参数起 |
| 链式推理（CoT） | "一步一步想"后能做复杂多步推理 | 数百亿参数起 |
| 指令遵循 | 理解并执行自然语言指令 | 指令微调后显现 |
| 代码生成 | 写出可运行代码 | 训练含代码后 |
| 跨语言迁移 | 用中文任务也能泛化（主要英文训练） | 大规模多语言数据 |
| 复杂推理与类比 | 解数学题、逻辑题、类比 | 千亿级 |
| 工具使用规划 | 自主拆解并调用工具 | RLHF/Agent 训练后 |

### 3. 可能成因

| 成因 | 说明 |
| --- | --- |
| 规模量变到质变 | 参数/数据到一定量，表征能力跨过门槛 |
| 数据多样性 | 海量多样数据触发泛化 |
| 训练目标 | next-token 预测在足够规模下逼出推理 |
| 能力潜伏 | 小模型已有雏形，但精度不足未体现 |
| 评估度量的相变 | 某些指标（如 exact match）在阈值前为 0、阈值后跳变 |
| 顿悟（Grokking） | 训练足够久后突然泛化，从记忆转向泛化 |

### 4. 学术争议：是真"涌现"还是度量假象

2023 Schaeffer et al. 提出争议：很多"涌现"可能是**评估指标选择**造成的假象。

| 观点 | 论据 |
| --- | --- |
| 真涌现 | 能力确在小模型上几乎为 0、大模型突现，且换任务一致 |
| 度量假象 | 用非线性/全有或无指标（exact match）才看着像突变；换成连续指标（token 级 log-likelihood）后曲线变平滑，"相变"消失 |
| 折中 | 部分能力是真涌现，部分是度量放大；需更细粒度评估 |

> 启示：判断某能力是否"涌现"，要看换不同度量后是否仍突变，避免被指标误导。

### 5. 一句话总结

涌现能力指模型规模突破阈值后突现的、小模型不具备的能力（少样本学习/CoT/指令遵循等），可能源于规模质变、数据多样、能力潜伏与度量相变；但部分"涌现"可能是全有或无评估指标造成的假象，需用连续度量甄别。
