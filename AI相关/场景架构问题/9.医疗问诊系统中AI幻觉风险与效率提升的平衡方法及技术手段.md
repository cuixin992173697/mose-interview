## 医疗问诊系统中 AI 幻觉风险与效率提升的平衡方法及技术手段

### 1. 医疗场景的特殊性

| 维度 | 要求 |
| --- | --- |
| 幻觉代价 | 错误诊断建议可能致命，容错极低 |
| 合规 | 受监管，需可追溯、可解释 |
| 知识权威性 | 必须基于权威医学知识，不能凭模型参数记忆 |
| 效率需求 | 分诊/预问诊/报告解读/科普，能大幅省医生时间 |

核心矛盾：**要效率（AI 自动化）又要安全（不能给错诊断）**。

### 2. 效率提升的应用点

| 应用点 | 价值 | 风险等级 |
| --- | --- | --- |
| 智能分诊 | 引导患者选对科室，减少错挂 | 中 |
| 预问诊 | 结构化采集症状病史，医生接诊前已知情 | 中 |
| 报告解读 | 把检验/影像报告翻译成患者能懂的话 | 高 |
| 健康科普 | 通用医学知识讲解 | 低 |
| 辅助诊断参考 | 给医生候选诊断提示 | 极高 |

### 3. 平衡方法：安全优先的分层布防

| 方法 | 作用 |
| --- | --- |
| RAG 强溯源 + 权威知识库 | 答案只来自权威医学文献/指南，可溯源，见 rag 目录《27.RAG系统幻觉问题的实用解决方法》 |
| Prompt 约束 + 强制拒答 | 明确"仅依据提供资料，不足则告知就医，不得下诊断" |
| 置信度阈值 | 低置信直接转人工/提示就医 |
| 人工复核兜底 | 高风险结论（诊断/用药）必须医生复核 |
| 多模型交叉验证 | 多模型/多次生成取一致部分，矛盾降权 |
| 角色定位：只给参考不下诊断 | AI 定位为辅助，诊断权归医生 |

### 4. 技术手段清单

| 环节 | 技术手段 |
| --- | --- |
| 知识供给 | RAG（权威指南/药品库/文献）+ 混合检索 + Rerank 精排 |
| 答案约束 | Prompt 强约束 + 强制引用溯源，见 rag 目录《28.RAG系统中信息来源标注与引用的实现方式》 |
| 校验 | 引用核对（结论必须在召回证据内）+ NLI 校验答案是否被证据支持 |
| 兜底 | 置信度阈值 + 敏感词检测 + 转人工 |
| 监控 | 幻觉率监控 + 不良反馈闭环 |

### 5. 安全合规红线

| 红线 | 说明 |
| --- | --- |
| 不直接下诊断 | AI 只提供参考信息，诊断由医生做出 |
| 不直接开药方 | 用药建议需医生确认 |
| 紧急症状强制引导就医 | 危急重症不靠 AI，直接引导急诊 |
| 全程可溯源 | 每条建议可追溯到权威来源 |
| 数据隐私 | 患者数据脱敏、合规存储 |
| 免责声明 | 明示 AI 辅助性质，不替代医生 |

### 6. 一句话总结

医疗问诊 AI 的平衡 = **效率上做分诊/预问诊/报告解读/科普，安全上靠 RAG 强溯源权威知识 + Prompt 强制拒答 + 置信度兜底 + 人工复核 + 多模型交叉验证 + 只给参考不下诊断**——安全优先于效率，诊断权永远归医生，幻觉抑制手段见 rag 目录《27.RAG系统幻觉问题的实用解决方法》《28.RAG系统中信息来源标注与引用的实现方式》。
