## 向量数据库中余弦相似度、欧几里得距离、曼哈顿距离的定义及差异

### 1. 三种度量定义

#### 余弦相似度（Cosine Similarity）

衡量两个向量**方向的夹角**，忽略幅度：

```
cos(A, B) = (A·B) / (||A|| × ||B||)        # 取值 [-1, 1]，越接近 1 越相似
```

- 只看方向不看长度，归一化后等价于点积。
- 文本 embedding 经归一化后多用此度量，因为语义相似体现在方向而非幅度。

#### 欧几里得距离（Euclidean Distance，L2）

两个向量在空间中的**直线距离**：

```
d(A, B) = √Σ (Aᵢ - Bᵢ)²                   # 取值 [0, +∞)，越小越相似
```

- 受向量幅度影响，幅度差异大的向量即使方向相近，距离也可能大。
- 图像/数值特征等幅度有意义的场景常用。

#### 曼哈顿距离（Manhattan Distance，L1）

各维度差绝对值之和，"城市街区距离"：

```
d(A, B) = Σ |Aᵢ - Bᵢ|                      # 取值 [0, +∞)，越小越相似
```

- 沿坐标轴逐维累加，对异常值比 L2 更鲁棒（不平方放大）。
- 网格化/稀疏高维场景偶有使用。

### 2. 差异对比

| 维度 | 余弦相似度 | 欧几里得距离（L2） | 曼哈顿距离（L1） |
| --- | --- | --- | --- |
| 衡量对象 | 方向（夹角） | 空间直线距离 | 各维差绝对值和 |
| 是否受幅度影响 | 否（归一化后） | 是 | 是 |
| 是否受方向影响 | 是（核心） | 间接 | 间接 |
| 取值范围 | [-1, 1] | [0, +∞) | [0, +∞) |
| 几何含义 | 向量夹角余弦 | 两点直线距离 | 坐标轴路径长度 |
| 计算成本 | 中（需归一化+点积） | 中（平方和开方） | 低（绝对值求和） |
| 对异常值敏感度 | 低 | 高（平方放大） | 中 |
| 典型场景 | 文本语义相似度 | 图像/数值特征 | 网格/稀疏数据 |

### 3. RAG 中为何多用余弦相似度

| 理由 | 说明 |
| --- | --- |
| 语义在方向上 | 文本经 embedding 后，**语义相似性主要体现在向量方向**，而非幅度；余弦正好衡量方向 |
| 对文本长度鲁棒 | 长短文本经模型编码后向量幅度可能不同，但只要语义相近方向就接近——余弦自动消除幅度干扰 |
| 归一化后等价点积 | embedding 模型通常要求归一化，归一化后余弦相似度 = 点积，计算高效 |
| 主流模型默认 | OpenAI/BGE 等embedding 模型在训练时多以余弦相似度为目标，配套使用最契合 |

> 工程提示：用余弦时记得对向量做 L2 归一化；很多向量库（Milvus/Qdrant）支持 `COSINE` 度量并自动归一化。详见 [[38.RAG中文本相似度的计算方法及常见算法]]，embedding 原理见 [[12.解读RAG中的Embedding嵌入技术]] 与 [[39.RAG中Embedding向量化的定义及工作原理]]。

### 4. 一句话总结

余弦相似度看**方向**、欧几里得看**直线距离**、曼哈顿看**街区距离**；RAG 文本检索因语义体现在方向且要对文本长度鲁棒，故多用余弦相似度（归一化后等价点积，计算高效）。
