## RAG 中常用的 Embedding 模型

### 1. Embedding 模型在 RAG 中的角色
Embedding 模型把文本映射成稠密向量，是 RAG 向量检索的基石——问题和文档都用同一个模型编码，才能在同一向量空间算相似度。

- 一句话：**选错 Embedding 模型，向量检索的召回上限就被锁死。**
- 原理详见 [[12.解读RAG中的Embedding嵌入技术]]。

### 2. 常用模型分类与清单

#### 中文模型
| 模型 | 维度 | 最大输入 | 特点 |
| --- | --- | --- | --- |
| bge-large-zh（BAAI） | 1024 | 512 | C-MTEB 长期榜首，开源，支持 instruction |
| bge-base-zh / bge-small-zh | 768/384 | 512 | 轻量版，资源受限场景 |
| m3e-large / m3e-base | 1024/768 | 512 | 中文社区早期主流，开源 |
| text2vec-large-chinese | 1024 | 256 | 老牌中文模型，效果一般 |

#### 英文模型
| 模型 | 维度 | 最大输入 | 特点 |
| --- | --- | --- | --- |
| OpenAI text-embedding-3-large | 3072 | 8192 | 商用 API，效果强，支持降维 |
| OpenAI text-embedding-3-small | 1536 | 8192 | 性价比高 |
| OpenAI ada-002（旧版） | 1536 | 8192 | 已被 v3 取代 |
| bge-large-en | 1024 | 512 | 开源，英文 MTEB 领先 |
| E5 / E5-large（微软） | 1024 | 512 | 开源，支持 instruction |
| GTE（阿里） | 1024 | 512 | 开源，英文表现强 |

#### 多语言模型
| 模型 | 维度 | 最大输入 | 特点 |
| --- | --- | --- | --- |
| bge-m3 | 1024 | 8192 | 稠密+稀疏+多向量三合一，100+ 语言，开源 |
| multilingual-e5-large | 1024 | 512 | 多语言通用，开源 |
| Cohere embed-multilingual-v3 | 1024 | 512 | 商用 API，多语言强 |

#### 商用 API
| 提供商 | 模型 | 特点 |
| --- | --- | --- |
| OpenAI | text-embedding-3-large/small | 接入最简单，按量计费 |
| Cohere | embed-v3（英/多语言） | 企业级，支持稀疏+稠密 |
| Voyage | voyage-2/3 / voyage-large | 专为 RAG 优化，MTEB 表现优异 |

### 3. 性能参考：MTEB / C-MTEB
- MTEB（Massive Text Embedding Benchmark）：英文综合评测榜，覆盖检索/分类/聚类/STS 等任务。
- C-MTEB：中文版，覆盖中文检索/分类/重排等。
- 检索任务看 **Retrieval** 子榜的 nDCG@10，最贴近 RAG 场景。
- 注意：榜单是通用评测，**不代表你的业务领域最优**，需用自有数据验证。

### 4. 选型速览
| 场景 | 推荐模型 |
| --- | --- |
| 纯中文、私有部署 | bge-large-zh（首选）/ m3e-large |
| 纯英文、私有部署 | bge-large-en / E5-large |
| 中英混合 / 多语言 | bge-m3（首选，长文本友好） |
| 不想部署、求快 | OpenAI text-embedding-3-small |
| 极致效果、愿付费 | OpenAI text-embedding-3-large / Voyage-large |

选型细节见 [[14.RAG中Embedding模型的选型因素及方法]]、[[32.RAG系统Embedding模型的选型方法]]。

### 5. 一句话总结
RAG 常用 Embedding 模型分中文（bge-large-zh/m3e）、英文（OpenAI v3/bge-en/E5）、多语言（bge-m3）三类，开源首选 bge 系列、商用首选 OpenAI v3，**具体选型不能只看 MTEB 榜单，必须用自有业务数据验证检索效果**。
