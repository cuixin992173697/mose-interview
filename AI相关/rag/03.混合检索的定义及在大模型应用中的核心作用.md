## 混合检索的定义及在大模型应用中的核心作用

### 1. 什么是混合检索（Hybrid Retrieval）

混合检索 = **把多种检索算法的结果融合**，取长补短，得到比单一算法更全、更准的召回。

最常见的组合是 **向量检索（稠密）+ 关键词检索（稀疏）**：

| 检索方式 | 代表算法 | 擅长 | 短板 |
| --- | --- | --- | --- |
| 稠密向量检索 | Embedding + ANN（余弦相似度） | 语义相似、同义改写、泛化 | 精确关键词/专有名词/数字易漏 |
| 稀疏关键词检索 | BM25 / TF-IDF | 精确词命中、专有名词、代码标识符 | 不懂同义、词面不匹配就召回不到 |

> 经典互补场景：问"GPT-4 的定价"，向量检索可能召回一堆讲定价的文档但漏掉含字面 "GPT-4" 的；BM25 则精确命中 "GPT-4" 字面——两者融合才稳。

### 2. 为什么单一检索不够

| 失败场景 | 单一方式的问题 | 混合后如何补救 |
| --- | --- | --- |
| 专有名词/型号/代码 | 向量检索语义模糊，召回不到精确词 | BM25 精确命中 |
| 同义改写/换个说法 | BM25 词面不匹配，召回为空 | 向量检索靠语义命中 |
| 多语言/跨语言 | BM25 跨语言失效 | 向量检索跨语言泛化 |
| 数字、ID、金额 | 向量把数字语义化，易混淆 | BM25 精确匹配 |

一句话：**向量检索懂"意思"，关键词检索懂"字面"，混合检索让两者都上线。**

### 3. 融合策略：怎么把两路结果合一起

#### 策略一：分数加权融合（Weighted）

把两路的相关性分数归一化后加权求和：

```
final_score = α * norm(dense_score) + (1-α) * norm(sparse_score)
```

- 需要先归一化（min-max / z-score），因为两路分数量纲不同。
- α 是调参点，通常经验值 0.5~0.7。

#### 策略二：RRF（Reciprocal Rank Fusion，倒数排名融合）——工业最常用

不看分数，只看排名，公式：

```
RRF_score(d) = Σ  1 / (k + rank_i(d))     # k 常取 60
```

- 优点：**无需归一化**，对不同检索器的分数尺度不敏感，鲁棒。
- 缺点：只用了排名信息，丢失了分数的绝对差异。
- 几乎所有主流向量库（Milvus、Weaviate、Elasticsearch、Qdrant）都内置 RRF。

| 融合方式 | 是否需归一化 | 信息利用 | 适用 |
| --- | --- | --- | --- |
| 加权融合 | 是（必须） | 分数 + 排名 | 检索器分数可靠、可比时 |
| RRF | 否 | 仅排名 | 异构检索器、分数不可比时（默认首选） |

#### 策略三：级联 / 多阶段

先 BM25 召回一批 + 向量召回一批，合并去重后交给 Rerank 精排（见 [[02.RAG中Rerank的含义及实现方式]]）。

### 4. 在大模型应用中的核心作用

混合检索不是 RAG 专属，但在大模型场景下价值被放大：

| 作用 | 说明 |
| --- | --- |
| 提升召回质量 | 兼顾语义与字面，召回率↑，直接减少"检索不到 → 幻觉" |
| 支撑精确问答 | 代码、SKU、合同条款、药品名等强字面场景，向量检索搞不定，必须靠稀疏检索补位 |
| 降低幻觉 | 召回更全更准 → 上下文证据更充分 → 大模型"有据可依"，幻觉率下降 |
| 增强可溯源 | 关键词命中位置明确，便于高亮引用与溯源 |
| 兼容多模态结构化数据 | 可叠加 Text-to-SQL、图检索等，组成更复杂的"多路混合" |

### 5. 工程实践要点

| 要点 | 说明 |
| --- | --- |
| 双索引并存 | 同一份文档既建向量索引又建 BM25/全文索引，存储成本翻倍但召回质量收益大 |
| 权重调参 | α 或 RRF 的 k 需基于评测集调；不同业务最优值不同 |
| 评测驱动 | 用 recall@k / MRR / nDCG 量化，别凭感觉 |
| 与 Rerank 配合 | 混合检索做"宽召回"，Rerank 做"精排序"，工业级 RAG 标配组合拳 |
| 增量更新 | 向量索引增量容易，BM25 倒排也支持增量，注意双路同步 |

### 6. 一句话总结

混合检索 = **稠密向量（懂语义）+ 稀疏关键词（懂字面）多路召回 + RRF/加权融合**，在大模型应用里负责"把该召回的一个不漏"，是 RAG 提升检索质量、降低幻觉的基石，通常再接 Rerank 做精排。
