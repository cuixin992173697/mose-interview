## RAG 中噪声文档的处理方法及文档去重、过滤实现

> 噪声文档（乱码/无关/低质/重复/模板化）会污染向量库、拉低召回精度、浪费 token。本篇讲去重与过滤。数据清洗全流程见 rag 目录的《05.RAG应用中，优化检索精度的数据清洗与预处理方法》，文档解析见《15.RAG索引流程中文档解析的实现方式》。

### 1. 噪声文档来源

| 噪声类型 | 来源 | 危害 |
| --- | --- | --- |
| 乱码 | 编码错误/OCR 错误/解析错误 | embedding 失真，召回噪声 |
| 无关文档 | 知识库混入非业务文档 | 占 top-K，挤掉相关结果 |
| 低质文档 | 内容空洞/太短/信息密度低 | 向量语义模糊，召回不准 |
| 重复/近重复 | 同一文档多份/转载/版本堆积 | 同一信息多次召回，浪费上下文 |
| 模板化文档 | 页眉页脚/版权声明/导航条反复出现 | 向量被无关文本稀释 |

### 2. 去重

| 方法 | 原理 | 适用 |
| --- | --- | --- |
| 精确哈希去重 | 文档/chunk 内容算 MD5/SHA，相同即重复 | 完全相同的重复 |
| 近重复 MinHash | 对文档 shingling 后用 MinHash 估计 Jaccard 相似度，超阈值判近重复 | 转载/微改/版本堆积 |
| 近重复 SimHash | 64 位指纹 + 海明距离判近重复 | 大规模近重复，速度快 |
| 向量去重 | embedding 后向量余弦相似度超阈值判重复 | 语义级重复（表述不同但内容相同） |

### 3. 过滤

| 过滤项 | 方法 |
| --- | --- |
| 质量评分 | 用 LLM/规则给文档打分，低分丢弃 |
| 长度/信息密度 | 过短（<阈值）、信息密度过低（大量空白/重复）丢弃 |
| 模板去除 | 识别并剥离反复出现的页眉页脚/版权/导航 |
| 语言检测 | 检测语言，过滤非目标语言或分流不同索引 |
| 敏感过滤 | 敏感词/隐私信息过滤或脱敏 |
| 乱码检测 | 字符分布异常/可读性低判乱码丢弃 |

### 4. 实现流程与代码示例（MinHash 去重）

```
原始文档 → 解析 → 清洗(去模板/乱码) → 质量过滤 → 去重(精确哈希+MinHash) → 切片 → 入库
```

MinHash 近重复去重示例：

```python
from datasketch import MinHash, MinHashLSH

def minhash_of(text, num_perm=128):
    m = MinHash(num_perm=num_perm)
    for word in text.split():
        m.update(word.encode('utf8'))
    return m

lsh = MinHashLSH(threshold=0.8, num_perm=128)   # 相似度阈值 0.8
seen = {}
for doc_id, text in docs.items():
    mh = minhash_of(text)
    dup = lsh.query(mh)                          # 查近重复
    if dup:
        print(f"{doc_id} 与 {dup} 近重复，丢弃")
        continue
    lsh.insert(doc_id, mh)
    seen[doc_id] = text
```

### 5. 一句话总结

噪声文档处理 = **先清洗（去模板/乱码/低质）→ 再去重（精确哈希 + MinHash/SimHash 近重复）→ 后过滤（质量评分/长度/语言/敏感）**，在切片入库前把噪声挡在向量库外，从源头保召回精度。一致性保障与脏数据规避见 [[2.文档频繁更新与删除场景下向量库的实时一致性保障及旧数据、脏数据规避]]。
