## 中英文混合文档场景下 Embedding 模型的选型方法：平衡效果与速度

> 知识库里中英文混杂（中文说明书 + 英文 spec + 代码注释 + 中英混排术语），Embedding 选型不当会导致跨语言召回塌方。本篇讲选型与"效果—速度"平衡。模型清单见 rag 目录的《13.RAG中常用的Embedding模型》，选型因素见《14.RAG中Embedding模型的选型因素及方法》，选型方法见《32.RAG系统Embedding模型的选型方法》。

### 1. 中英文混合文档的检索难点

| 难点 | 表现 | 对 Embedding 的要求 |
| --- | --- | --- |
| 跨语言语义对齐 | 问中文"大模型"要能召回到英文写"LLM"的文档 | 模型需在中英向量空间对齐同义概念 |
| 词表覆盖 | 英文术语/代码标识符/罕见词被拆成子词甚至乱码 | 词表含中英 + 代码 token，子词覆盖好 |
| 分词差异 | 中文需分词、英文按空格、中英混排边界混乱 | 模型自带多语言分词，不依赖外部分词器 |
| 双语对齐 | 同一概念中英两种表述，向量应靠近 | 训练时需跨语言对比学习/翻译对数据 |
| 混排文档 | 一段话里中英夹杂（"用 RAG 做 QA"） | 能整体编码混排句，不丢任一语言语义 |

> 单语模型（纯中文或纯英文）在混合场景下跨语言召回率会断崖式下跌——问中文召回不到英文文档，反之亦然。

### 2. 选型方向

| 方向 | 代表模型 | 优点 | 缺点 | 适用 |
| --- | --- | --- | --- | --- |
| 多语言模型 | bge-m3、multilingual-e5、GTE-multilingual | 跨语言对齐好，覆盖几十种语言 | 模型大、推理稍慢 | 中英+其他语言，跨语言召回要求高 |
| 中英双语模型 | bge-large-zh-v1.5（中英兼顾）、m3e-base | 中英效果均衡，速度适中 | 非中英语言覆盖弱 | 主力中英，少量其他 |
| 单语言 + 翻译桥接 | 中文模型 + 翻译把英文文档/问题转成同语言 | 可用单语强模型 | 翻译延迟/误差、丢失原文 | 极端追求单语效果 |
| 商用多语言 API | OpenAI text-embedding-3、Cohere、Voyage | 效果稳、免部署 | 成本、数据出境、延迟 | 不敏感场景快速验证 |

> 经验首选：**bge-m3**（开源、多语言、支持稠密+稀疏+多向量，中文场景表现强）或 **multilingual-e5-large**（跨语言对齐经典）。纯中英且追求速度可用 bge-large-zh-v1.5。

### 3. 效果 vs 速度平衡

| 杠杆 | 提效果 | 提速度 |
| --- | --- | --- |
| 模型大小 | large 版精度高 | base/small 版快 2~4 倍 |
| 向量维度 | 高维（1024+）信息量大 | 低维（384/768）存储检索快 |
| 量化 | FP32 精度最高 | INT8/FP16 量化，速度↑、存储↓、精度损失小 |
| 批处理 | — | batch embedding 充分用 GPU |
| 缓存 | — | 文档向量离线预计算；query 向量缓存 |
| 异步 | — | 建库离线批量，查询在线只算 query 向量 |

| 配置 | 效果 | 速度 | 适用 |
| --- | --- | --- | --- |
| bge-m3 FP32 large | ★★★★★ | ★★ | 离线索引/精度优先 |
| bge-m3 INT8 | ★★★★☆ | ★★★★ | 生产主力（推荐） |
| bge-base-zh FP16 | ★★★★ | ★★★★★ | 延迟敏感/海量文档 |
| multilingual-e5-base | ★★★★ | ★★★★ | 跨语言均衡 |

### 4. 评测：用中英文混合评测集对比

选型不能凭感觉，必须用业务混合语料建评测集：

| 步骤 | 做法 |
| --- | --- |
| 建评测集 | 采 200~500 条真实 query（中文问/英文问/中英混问）+ 人工标注相关文档（含中英） |
| 跑指标 | recall@k、MRR、跨语言命中率（中文问→英文文档、英文问→中文文档） |
| 对比模型 | 同评测集跑 bge-m3 / multilingual-e5 / bge-large-zh 等，看 recall/MRR |
| 速度压测 | 测 embedding 吞吐 + 检索 P99 延迟 |

> 关键看"跨语言命中率"：用中文 query 能否召回到英文文档，这是单语模型的盲区，也是多语言模型选型的核心价值。

### 5. 一句话总结

中英文混合文档选 Embedding：**首选多语言模型（bge-m3/multilingual-e5）做跨语言语义对齐，用 INT8 量化 + base 版本平衡速度，用中英文混合评测集的跨语言 recall/MRR 做选型决策**——别在单语模型上赌跨语言召回。距离度量的选型见 [[12.向量检索中余弦相似度、点积、欧氏距离的实际应用差异及选型]]。
