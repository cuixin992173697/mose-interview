## RAG 检索无关片段的规避方法及 LLM 回答跑偏的优化手段

> 召回一堆无关片段塞进上下文，LLM 就容易被带偏、甚至幻觉。本篇讲检索层怎么挡住无关片段、生成层怎么防 LLM 跑偏。召回不匹配的改进见 rag 目录的《24.RAG系统召回结果与用户query意图不匹配的改进方向》，幻觉治理见《27.RAG系统幻觉问题的实用解决方法》，Rerank 见《02.RAG中Rerank的含义及实现方式》，阈值见《49.RAG检索中相似度阈值的设置方法及设置不当的影响》。

### 1. 无关片段从哪来

| 来源 | 说明 |
| --- | --- |
| 召回噪声 | 向量检索语义模糊，召回到看似相关实则无关的片段 |
| 阈值过低 | 相似度阈值设太低，低相关片段也混进来 |
| top-K 过大 | K 设太大，把排名靠后的弱相关/无关片段也纳入 |
| 查询不准 | query 表述差/口语化，召回方向偏 |
| 缺元数据过滤 | 没按来源/时间/类别预过滤，跨域噪声混入 |

### 2. 检索层：规避无关片段

| 方法 | 说明 |
| --- | --- |
| 相似度阈值 | 召回分数低于阈值的直接丢弃，宁缺毋滥（见 rag 目录《49》） |
| Rerank 精排 | Cross-Encoder 对召回结果重排，无关片段排不进 top-K（见 [[13.RAG中rerank重排模型的选型及重排速度优化方法]]） |
| 元数据过滤 | 检索前按来源/时间/类别/权限预过滤，缩小搜索空间、挡跨域噪声 |
| 查询优化 | 查询改写/扩展让召回更准，从源头减少无关（见 [[4.模糊用户问题的意图识别、查询改写及多路召回优化方法]]） |
| 减小 K | 上下文预算允许下用更小 K + Rerank，而非大 K 硬塞 |
| 阈值+K 双控 | 既限 K 又限阈值，双重过滤 |

### 3. 生成层：防 LLM 回答跑偏

即便召回里有少量无关片段，也要让 LLM 不被带偏：

| 手段 | 说明 |
| --- | --- |
| Prompt 约束 | 明确"仅依据提供的上下文回答，上下文无依据则回答'不知道'" |
| 强溯源 | 要求每句结论标注来源片段编号，无来源的结论判违规 |
| 无关拒答 | 召回片段均与问题无关时，直接拒答而非硬编 |
| 上下文聚焦 | Prompt 引导模型优先关注高相关（Rerank 靠前）片段 |
| 答案校验 | 生成后用 NLI/LLM 校验"答案是否被上下文支持"，不支持则剔除/重答 |
| 片段排序 | 上下文组装时把最相关放首尾（规避 lost-in-the-middle） |

Prompt 模板示例：

```text
你是一个严谨的问答助手。请严格依据下方【参考资料】回答问题。
规则：
1. 答案中每个事实性结论必须能在参考资料中找到依据，并标注 [编号]。
2. 若参考资料中没有相关信息，直接回答"根据现有资料无法回答"，不得编造或自行发挥。
3. 忽略与问题无关的资料，不要被其带偏。
4. 资料间冲突时，说明冲突并优先采信更权威/更新的来源。

【参考资料】
[1] ...
[2] ...
【问题】...
```

### 4. 检索 + 生成双层防线

| 层 | 挡什么 | 手段 |
| --- | --- | --- |
| 检索层 | 挡住无关片段进上下文 | 阈值 + Rerank + 元数据过滤 + 查询优化 + 控 K |
| 生成层 | 即便有无关片段，防 LLM 被带偏 | Prompt 约束 + 强溯源 + 拒答 + 答案校验 |

> 两层互补：检索层做减法（少塞噪声），生成层做约束（塞了也不乱答）。

### 5. 无关片段与跑偏的常见场景对照

| 场景 | 检索层对策 | 生成层对策 |
| --- | --- | --- |
| 跨域噪声（问 A 召回 B） | 元数据过滤 + 阈值 | 拒答（无相关依据） |
| 弱相关片段混入 | Rerank 精排 + 减小 K | 强溯源（无来源剔除） |
| 召回全无关 | 阈值判空 → 走拒答流程 | 直接拒答，不硬编 |
| 模型忽略证据瞎编 | — | Prompt 约束 + 答案校验 |
| 片段冲突致跑偏 | Rerank 排序 + 时间/权威优先 | 冲突说明 + 优先采信 |

### 6. 一句话总结

防无关片段与 LLM 跑偏要**双层布防**：检索层用相似度阈值 + Rerank 精排 + 元数据过滤 + 查询优化 + 控制 K 挡住无关片段，生成层用 Prompt 约束（仅依上下文）+ 强溯源 + 无关拒答 + 答案校验防止模型被带偏——检索做减法、生成做约束，两层互补。模糊问题优化见 [[4.模糊用户问题的意图识别、查询改写及多路召回优化方法]]，Rerank 选型见 [[13.RAG中rerank重排模型的选型及重排速度优化方法]]。
