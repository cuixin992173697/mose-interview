## Agent 任务完成率的评估方法及生产中的核心统计指标（成功率、错误率等）

> Agent 上线后，"到底跑得好不好"必须量化。本篇讲任务完成率评估方法与生产核心统计指标。RAG 侧评估见 rag 目录的《09.RAG调优后效果评估的方法及实际应用中的评估标准》《50.RAG系统效果的评估方法及检索、生成环节的核心评估指标》。

### 1. 任务完成率定义

**任务完成率 = 成功完成的任务数 / 总任务数**

关键在"成功完成"的判定标准：任务达到预期目标、无人工干预、无错误中断、结果正确。

| 判定维度 | 说明 |
| --- | --- |
| 目标达成 | 任务最终输出满足用户预期目标 |
| 无致命错误 | 未因错误中断且未兜底回复 |
| 无人工干预 | 全程自主完成（人工干预率另统计） |
| 结果正确 | 输出事实正确、符合约束 |

### 2. 评估方法

| 方法 | 说明 | 适用 |
| --- | --- | --- |
| 端到端任务评测集 | 离线构造代表性任务集 + 预期结果，跑 Agent 算完成率 | 迭代调优、回归 |
| 人工标注 | 人工评判线上样本任务是否真正完成 | 金标准、校准自动评估 |
| LLM-as-judge | 用大模型自动评判任务完成质量 | 大规模自动评估，需校准 |
| 线上 A/B | 不同版本/Prompt/模型在线分流对比完成率 | 上线决策 |
| 用户反馈 | 点赞/点踩/重试率/满意度评分 | 真实体验信号 |

> 离线评测集 + LLM-as-judge 自动跑 + 抽样人工校准 + 线上 A/B 决策，是工业常用组合。

### 3. 生产核心统计指标

| 指标 | 定义 | 意义 |
| --- | --- | --- |
| 成功率 | 成功任务/总任务 | 核心北极星 |
| 错误率 | 失败任务/总任务 | 成功率反面，需分类 |
| 错误分类 | LLM 错误/工具错误/超时/参数错/权限/上下文超限 | 定位改进方向 |
| 平均步数 | 完成任务的平均推理-行动轮数 | 效率，过多可能绕路 |
| 平均耗时 | 任务端到端平均时长 | 体验 |
| token 成本 | 单任务平均 token 消耗 | 成本 |
| 工具调用成功率 | 工具调用成功/总调用 | 工具链质量 |
| 人工干预率 | 需人工介入任务/总任务 | 自主程度 |
| 首次成功率 | 首次即成功（无重试）/总任务 | 一次做对的能力 |
| 用户满意度 | 点赞率/评分/重试率 | 真实体验 |
| P95/P99 耗时 | 长尾耗时 | 体验下限 |

### 4. 指标体系分层

| 层 | 指标 | 回答的问题 |
| --- | --- | --- |
| 业务指标 | 成功率、用户满意度、任务达成率、人工干预率 | 业务价值如何 |
| 系统指标 | 错误率、平均步数、平均/P95 耗时、工具调用成功率 | 系统跑得稳不稳 |
| 成本指标 | token 成本、API 调用成本、单任务成本 | 花了多少钱 |
| 质量指标 | 结果正确率、幻觉率、合规率 | 输出质量如何 |

### 5. 监控大盘与闭环

| 环节 | 做法 |
| --- | --- |
| 采集 | 每步输入输出 + traceId 落盘，见 [[11.Agent执行过程的可观测性设计及全链路追踪实现]] |
| 大盘 | 成功率/错误率/耗时/成本/干预率实时看板 + 告警阈值 |
| 归因 | 错误按分类下钻定位（哪个工具/哪步/哪个模型） |
| 闭环 | 低成功率场景→分析→改进（Prompt/工具/模型）→评测集回归→上线 A/B 验证 |

### 6. 一句话总结

Agent 生产评估以**任务完成率**为北极星，用"评测集+LLM-as-judge+人工校准+A/B"评估，核心统计指标分业务（成功率/满意度/干预率）、系统（错误率/步数/耗时）、成本（token）、质量（正确率/幻觉率）四层，配合监控大盘与归因闭环持续改进；可观测基础见 [[11.Agent执行过程的可观测性设计及全链路追踪实现]]。
