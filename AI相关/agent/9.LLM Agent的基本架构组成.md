## LLM Agent 的基本架构组成

### 1. 四大核心组成

LLM Agent 的经典架构 = **大脑（LLM）+ 规划（Planning）+ 记忆（Memory）+ 工具（Tools）**，外加感知（Perception）与行动（Action）接口。

```
                ┌─────────────────────┐
   感知输入 ──→ │   大脑（LLM）        │ ←──→ 记忆 Memory
                │  推理 / 决策 / 理解   │       (短期+长期)
                └────────┬────────────┘
                         │
              ┌──────────┴──────────┐
              │   规划 Planning      │
              │  (任务拆解/ReAct)    │
              └──────────┬──────────┘
                         │
              ┌──────────┴──────────┐
              │   行动 Action        │ ──→ 工具 Tools
              │  (调用工具/代码)      │     (API/检索/代码)
              └─────────────────────┘
                         │
                    观察结果回填 ──→ 回到大脑（循环）
```

### 2. 各组成详解

| 组成 | 职责 | 常见实现 |
| --- | --- | --- |
| 大脑（LLM） | 理解意图、推理决策、生成自然语言与工具调用 | GPT/Claude/Qwen 等 |
| 规划（Planning） | 把目标拆成步骤，决定先做什么后做什么 | ReAct、Plan-and-Execute、ToT、CoT |
| 记忆（Memory） | 存储上下文与历史经验 | 短期：对话窗口；长期：向量库/KV/图 |
| 工具（Tools） | 扩展 LLM 能力边界，与外部世界交互 | Function Calling、API、代码执行、RAG 检索 |

### 3. 大脑（LLM）

Agent 的核心引擎，负责：
- 理解用户意图与当前状态
- 推理下一步行动（Thought）
- 生成工具调用参数
- 综合观察结果输出最终答案

大脑能力直接决定 Agent 上限：推理强 → 规划准、工具用对、少死循环。

### 4. 规划（Planning）

把复杂目标拆解为可执行子任务：

| 策略 | 思路 |
| --- | --- |
| Task Decomposition | 大任务→子任务→子子任务，逐层细化 |
| ReAct | Thought→Action→Observation 循环（见 [[11.Agent智能体的核心工作流程]]） |
| Plan-and-Execute | 先整体规划再逐步执行 |
| ToT/GoT | 树/图状多路径探索，回溯选优 |

### 5. 记忆（Memory）

| 类型 | 存储位置 | 内容 |
| --- | --- | --- |
| 短期记忆 | LLM 上下文窗口 | 当前对话、最近工具结果 |
| 长期记忆 | 外部存储（向量库/KV/图） | 历史事件、用户偏好、经验 |

长期记忆实现详见 [[12.LLM Agent长期记忆能力的实现方法]]，短长期差异见 [[22.Agent系统中短期记忆与长期记忆的差异及存储检索方式]]。

### 6. 工具（Tools）

让 LLM 突破"只会说不会做"：

| 工具类型 | 示例 |
| --- | --- |
| 信息获取 | 搜索、RAG 检索、数据库查询 |
| 计算/执行 | Python/Shell、代码解释器 |
| 外部交互 | 发邮件、调业务 API、操作浏览器 |
| 子 Agent | 调用其他 Agent 协作 |

### 7. 各组成如何协同

```
用户目标
  → 大脑理解 + 规划拆解
  → 大脑决策调用工具
  → 工具执行，返回 Observation
  → 结果 + 记忆回填进上下文
  → 大脑再推理（够不够？下一步？）
  → 循环直到目标完成 → 输出
```

### 8. 一句话总结

LLM Agent 架构 = **大脑（LLM 推理）+ 规划（拆解步骤）+ 记忆（短期上下文+长期经验）+ 工具（扩展能力）**，通过感知→规划→行动→观察的循环协同完成目标；大脑是引擎、规划是路线、记忆是经验、工具是手脚。
