## 大模型 Agent 的定义及与传统 AI 系统的区别

### 1. 什么是大模型 Agent

大模型 Agent（智能体）= **以 LLM 为大脑，具备规划、记忆、工具使用能力，能感知环境、自主决策、循环执行直到完成目标的智能系统**。

一句话：传统程序"人写死逻辑让机器执行"，Agent"给机器目标和工具，让它自己想怎么做"。

| 组成 | 作用 |
| --- | --- |
| 大脑（LLM） | 推理、理解意图、生成决策 |
| 规划（Planning） | 把大目标拆成可执行步骤 |
| 记忆（Memory） | 短期上下文 + 长期经验 |
| 工具（Tools） | 调用外部 API/代码/检索扩展能力边界 |
| 自主循环 | 观察→思考→行动→反馈，循环推进 |

> 架构详见 [[9.LLM Agent的基本架构组成]]，工作流程详见 [[11.Agent智能体的核心工作流程]]。

### 2. 与传统 AI 系统的区别

传统 AI 系统（规则引擎、有限状态机、固定流水线、传统 ML）与大模型 Agent 的本质差异：

| 维度 | 传统 AI 系统 | 大模型 Agent |
| --- | --- | --- |
| 决策方式 | 预定义规则/状态机/固定模型 | LLM 实时推理决策 |
| 泛化能力 | 仅覆盖训练/规则覆盖的场景 | 自然语言理解，泛化到未见任务 |
| 工具使用 | 固定硬编码调用 | 运行时动态选择调用 |
| 记忆 | 通常无或固定状态 | 短期上下文 + 长期记忆库 |
| 自主性 | 被动执行单步 | 自主规划多步、循环推进 |
| 适配新任务 | 需重写规则/重训模型 | 改 Prompt/加工具即可 |
| 失败处理 | 报错中断 | 自我修正、重试、换方案 |
| 输出确定性 | 高（同输入同输出） | 低（有随机性，需约束） |

### 3. Agent 的核心特征

| 特征 | 说明 |
| --- | --- |
| 自主性（Autonomy） | 无需人逐步指令，自己规划并执行 |
| 反应性（Reactivity） | 感知环境/工具反馈，实时调整 |
| 目标驱动（Goal-driven） | 围绕目标推进，而非机械执行 |
| 主动性（Proactiveness） | 不只被动响应，能主动规划前瞻行动 |
| 学习/记忆 | 积累经验，跨会话复用 |

### 4. 一句话总结

大模型 Agent = **LLM 大脑 + 规划 + 记忆 + 工具 + 自主循环**，本质区别在于"决策由 LLM 实时推理产生"而非"人预写规则"——这让 Agent 能泛化到新任务、自主多步推进，代价是确定性下降、需更强的工程约束。
