## LangChain 的核心组件详解

### 1. 组件全景

| 组件 | 职责 | 典型用法 |
| --- | --- | --- |
| DocumentLoader | 加载各类文档为 Document 对象 | PyPDFLoader / UnstructuredLoader / WebBaseLoader |
| TextSplitter | 切片 | RecursiveCharacterTextSplitter / MarkdownHeaderTextSplitter |
| Embeddings | 文本向量化 | OpenAIEmbeddings / HuggingFaceEmbeddings |
| VectorStore | 向量存储与检索 | FAISS / Chroma / Milvus / Pinecone |
| Retriever | 检索器抽象（query → Document[]） | vectorstore.as_retriever() / BM25Retriever / EnsembleRetriever |
| LLM & ChatModel | 模型抽象 | ChatOpenAI 等（见 [[5.LangChain model的核心含义及应用]]） |
| Chain | 链式组合（旧范式） | LLMChain / RetrievalQA |
| Agent | 自主决策 + 工具调用 | create_tool_calling_agent / AgentExecutor（见 [[4.LangChain Agent的定义及核心作用]]） |
| Memory | 对话记忆 | ConversationBufferMemory / ConversationSummaryMemory |
| OutputParser | 解析模型输出 | StrOutputParser / PydanticOutputParser |
| Callbacks | 事件回调 / 可观测 | StreamingStdOutCallbackHandler |

### 2. 各组件要点

#### DocumentLoader
统一把异构数据转成 `Document`（page_content + metadata）：

```python
from langchain_community.document_loaders import PyPDFLoader
docs = PyPDFLoader("a.pdf").load()
```

#### TextSplitter

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_documents(docs)
```

#### Embeddings + VectorStore

```python
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings
vs = FAISS.from_documents(chunks, OpenAIEmbeddings())
```

#### Retriever
检索器是"输入 query → 输出 Document[]"的统一抽象，解耦存储与使用：

```python
retriever = vs.as_retriever(search_kwargs={"k": 4})
```

#### OutputParser
把模型字符串输出解析为结构化对象；`PydanticOutputParser` 配合格式化指令做结构化抽取。

### 3. 组合成 Pipeline

#### RAG pipeline（LCEL 声明式）

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_template("依据上下文回答：{context}\n问题：{question}")
llm = ChatOpenAI()
rag = {"context": retriever, "question": RunnablePassthrough()} | prompt | llm | StrOutputParser()
rag.invoke("什么是RAG？")
```

> 完整 LangChain RAG 实现见 rag 目录的《41.RAG的定义及基于LangChain的RAG应用实现》。

#### Agent pipeline

```python
from langchain.agents import create_tool_calling_agent, AgentExecutor
agent = create_tool_calling_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools, verbose=True)
executor.invoke({"input": "查北京今天天气并总结"})
```

### 4. 组件关系图

```
Loader → Splitter → Embeddings → VectorStore → Retriever ┐
                                                          ├→ Chain/Agent (Prompt + Model + Parser + Memory) → 输出
                                                     LLM ┘
```

### 5. 一句话总结

LangChain 由 Loader / Splitter / Embeddings / VectorStore / Retriever / Model / Chain / Agent / Memory / OutputParser / Callbacks 等可组合组件构成，分别覆盖"数据进、向量化、检索、推理、编排、记忆、解析、观测"，用 LCEL 或 AgentExecutor 串成 RAG / Agent pipeline。
