## LangChain 中 Chain 与 Agent 的定义及应用场景举例

### 1. Chain 的定义

Chain = **预定义执行序列**：把多个步骤按固定顺序串成一条管道，输入沿管道流转，每步的输出是下步的输入，整个流程是**确定性**的。

```
输入 → 步骤1 → 步骤2 → 步骤3 → 输出
```

| 特征 | 说明 |
| --- | --- |
| 流程 | 固定、预定义 |
| 决策 | 无 LLM 自主决策（LLM 只在某个步骤里被调用） |
| 确定性 | 高（同样输入走同样路径） |
| 可控性 | 高（路径可预测） |
| 典型 | LCEL `prompt | model | parser` |

### 2. Agent 的定义

Agent = **以 LLM 为决策核心**：不预设执行路径，由 LLM 根据当前状态动态选择"下一步调用哪个工具、传什么参数、何时结束"，流程是**非确定性**的。

```
输入 → [LLM 决策：调哪个工具？] → 执行 → 观察 → [LLM 再决策] → … → 最终答案
```

| 特征 | 说明 |
| --- | --- |
| 流程 | 动态、由 LLM 实时决定 |
| 决策 | LLM 自主推理决策 |
| 确定性 | 低（同样输入可能走不同路径） |
| 可控性 | 较低（需靠终止条件/最大步数兜底） |
| 典型 | ReAct / OpenAI Functions Agent |

### 3. Chain vs Agent 对比

| 维度 | Chain | Agent |
| --- | --- | --- |
| 决策方式 | 预定义序列，无自主决策 | LLM 自主决策下一步 |
| 确定性 | 确定性（路径固定） | 非确定性（路径动态） |
| 灵活性 | 低（改流程要改代码） | 高（LLM 适配新任务） |
| 可控性 | 高（路径可预测） | 低（需 max_steps/终止条件兜底） |
| 成本 | 低（固定步数） | 高（多轮 LLM 调用） |
| 延迟 | 低、稳定 | 高、波动 |
| 适用 | 固定、可枚举的流程 | 开放、需动态决策的任务 |

### 4. 应用场景举例

#### 选 Chain 的场景（流程固定、可枚举）

| 场景 | 为何用 Chain | 典型管道 |
| --- | --- | --- |
| RAG 问答 | 检索→生成流程固定，无需 LLM 决定走哪步 | `retriever | prompt | model | parser` |
| 文档摘要 | 单次"输入文档→生成摘要"，路径确定 | `stuff_prompt | model | parser` |
| 翻译 | 固定"原文→译后文本" | `translate_prompt | model | parser` |
| 信息抽取 | 固定"文本→结构化字段" | `extract_prompt | model | parser` |

#### 选 Agent 的场景（需动态决策）

| 场景 | 为何用 Agent | 典型工具 |
| --- | --- | --- |
| 多工具任务 | 需 LLM 判断该用哪个工具、用几次 | 搜索/计算器/数据库/代码执行 |
| 自主研究 | 目标开放，需多步检索+整合+追问 | 搜索/网页抓取/总结 |
| 浏览器/电脑操作 | 每步动作取决于上一步页面状态 | 点击/输入/截图/导航 |
| 复杂客服 | 按用户意图动态选查询/工单/转人工 | 查订单/建工单/转人工 |

> 一句话判断：**能事先画出流程图的用 Chain，画不出来、要靠 LLM 边走边看的用 Agent。**

### 5. 选型决策

| 问题 | 偏向 |
| --- | --- |
| 步骤能否在写代码时全部确定？ | 能 → Chain；不能 → Agent |
| 是否需要根据中间结果改变路径？ | 需要 → Agent |
| 对延迟/成本敏感、要求稳定？ | 是 → Chain |
| 任务开放、工具多、需自主？ | 是 → Agent |
| 既要稳定又要灵活？ | Chain 为主 + 关键节点嵌 Agent（混合） |

### 6. 一句话总结

Chain 是**固定管道**、确定性、可控低成本，适合可枚举的流程（RAG/摘要/翻译/抽取）；Agent 是 **LLM 动态决策**、非确定性、灵活高成本，适合开放任务（多工具/自主研究/浏览器操作）——能画出流程图用 Chain，画不出用 Agent。组件与组合方式见 [[2.LangChain的核心组件详解]]，Agent 定义见 [[4.LangChain Agent的定义及核心作用]]，二者差异详解见 [[47.LangChain中Agent的定义及与Chain的差异]]。
