## LangChain model 的核心含义及应用

### 1. model 抽象：LLM vs ChatModel

LangChain 把"模型"抽象为两大类：

| 类型 | 接口 | 输入 / 输出 | 典型 |
| --- | --- | --- | --- |
| LLM | 纯文本 | str → str | HuggingFacePipeline 等旧式 |
| ChatModel | 对话消息 | messages → AIMessage | ChatOpenAI / ChatAnthropic |

现代几乎都用 ChatModel（消息列表输入，支持 system / user / assistant / tool 角色）。

```python
from langchain_openai import ChatOpenAI
llm = ChatOpenAI(model="gpt-4o", temperature=0)
llm.invoke([{"role": "user", "content": "你好"}])
```

### 2. 统一调用接口（Runnable）

ChatModel 实现 Runnable 协议（见 [[3.LangChain的核心架构解析]]）：

| 方法 | 说明 |
| --- | --- |
| invoke | 单次同步 |
| stream | 流式逐 token |
| batch | 批量并行 |
| ainvoke / astream / abatch | 异步版本 |
| generate（旧） | 批量返回含 token 用量 |

### 3. 同步与异步

所有模型方法都有异步对应，便于高并发服务：

```python
await llm.ainvoke([...])
async for chunk in llm.astream([...]):
    print(chunk.content, end="")
```

### 4. 流式输出

```python
for chunk in llm.stream("讲个RAG的段子"):
    print(chunk.content, end="", flush=True)
```

流式是交互体验关键，LCEL 管道 `prompt | model | parser` 的 stream 会逐 token 透传。

### 5. 结构化输出

ChatModel 支持 `.with_structured_output()`，用 function calling / JSON mode 强制返回结构化对象：

```python
schema_llm = llm.with_structured_output({"name": str, "age": int})
obj = schema_llm.invoke("张三 30 岁")  # {'name': '张三', 'age': 30}
```

### 6. 在 Chain / Agent 中的底层角色

model 是 LCEL 管道 / Agent 循环的核心一环：

| 场景 | 角色 |
| --- | --- |
| RAG | 接收"检索片段 + 问题"，生成答案 |
| Agent | 接收"工具列表 + 历史"，决策调哪个工具 |
| 结构化抽取 | with_structured_output 输出对象 |
| 总结 / 改写 | 纯文本变换 |

> model 是组件之一，完整组件体系见 [[2.LangChain的核心组件详解]]。

### 7. 一句话总结

LangChain 把模型抽象为 LLM（纯文本）与 ChatModel（对话消息，现代主流），统一实现 Runnable 协议（invoke / stream / batch + 异步），支持流式与结构化输出，是 LCEL 管道与 Agent 循环中负责"推理决策 / 生成"的核心一环。
