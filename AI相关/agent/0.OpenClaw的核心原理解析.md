## OpenClaw 的核心原理解析

### 1. OpenClaw 是什么（定位）

OpenClaw 是一个**通用 LLM Agent 编排框架**——把"LLM 大脑 + 工具 + 记忆 + 多渠道接入"编排成一个可运行的 Agent 系统。它本身不提供 LLM，而是解决"LLM 如何在真实工程环境里持续、安全、多渠道地自主执行任务"这一工程问题。

| 对比 | 纯 LLM API | 简单 Agent 库（如早期 AgentExecutor） | OpenClaw |
| --- | --- | --- | --- |
| 关注点 | 单轮问答 | 单 Agent 工具循环 | 多渠道接入 + 上下文管理 + 多 Agent 路由 + 安全 |
| 上下文管理 | 调用方自理 | 简单拼接，易超限 | 可插拔 Context Engine + Compaction |
| 多渠道 | 无 | 无原生 | Channel Plugin 抽象 |
| 工具安全 | 无 | 基本无 | 工具策略管道分层管控 |
| 定位 | 能力 | 编排雏形 | 工程化编排平台 |

> 本系列中 OpenClaw 作为"通用 LLM Agent 编排框架"的代称，其机制按业界典型工程设计阐述，对应 LangGraph 执行循环、MemGPT/Letta 上下文管理、Claude Code 的 compaction、Bot Framework 的 channel 等真实概念。定义与核心问题见 [[23.OpenClaw的定义、核心问题及核心能力]]。

### 2. 核心原理（六大支柱）

OpenClaw 的运行由六个核心机制支撑，每个对应 Agent 工程的一个关键难点：

| 支柱 | 机制 | 解决的问题 |
| --- | --- | --- |
| ① 决策大脑 | 以 LLM 为核心做规划与工具选择 | 自主推理 |
| ② Context Engine | 可插拔的上下文管理抽象 | 上下文窗口受限、长对话、工具结果膨胀 |
| ③ Agent Runner | 执行引擎驱动 Thought→Action→Observation 循环 | 自主多步执行 |
| ④ Channel Plugin | 多渠道接入抽象层 | 异构渠道（Web/IM/语音/API）统一接入 |
| ⑤ Tool Pipeline | 工具策略管道分层管控 | 工具权限、审计、风险控制 |
| ⑥ Router | 多 Agent 消息路由 | 多 Agent 分发与协调 |

### 3. 设计哲学

| 哲学 | 含义 | 体现 |
| --- | --- | --- |
| 可插拔 | 核心组件皆可替换 | Context Engine / Channel / Tool 均为接口，可换实现 |
| 上下文优先 | 把上下文当一等公民管理 | 专门的 Context Engine + Compaction，而非简单拼接 |
| 多渠道原生 | 从入口就抽象渠道 | Channel Plugin 统一异构渠道 |
| 安全可控 | 工具调用需过策略管道 | 分层权限 + 审计 + 人工确认 |

### 4. 与 LangChain / LangGraph 的异同

| 维度 | LangChain | LangGraph | OpenClaw |
| --- | --- | --- | --- |
| 核心抽象 | Chain / Runnable | 状态图（节点+边） | 可插拔组件 + 执行循环 |
| 执行模型 | 链式 / LCEL 管道 | 图遍历 + 状态机 | Agent Runner 循环 |
| 上下文管理 | 调用方 / 简单 Memory | 状态对象 | 可插拔 Context Engine（一等公民） |
| 多渠道 | 无原生 | 无原生 | Channel Plugin 原生抽象 |
| 工具安全 | 基本无 | 基本无 | 工具策略管道分层 |
| 侧重 | 通用编排生态 | 复杂流程图编排 | 工程化部署（上下文 / 多渠道 / 安全） |

三者并非互斥：OpenClaw 这类框架的执行循环可与 LangGraph 的图编排互补，Context Engine 思路与 MemGPT/Letta、Claude Code 的 compaction 同源。

### 6. 一句话总结

OpenClaw 的核心原理 = **以 LLM 为决策大脑，用可插拔的 Context Engine 管上下文、Agent Runner 驱动执行循环、Channel Plugin 接多渠道、Tool Pipeline 控工具权限、Router 做多 Agent 路由**——把"能推理的 LLM"变成"能在真实工程环境持续安全自主运行的 Agent 系统"。组件关系见 [[24.OpenClaw的核心组件及组件间关系]]。
