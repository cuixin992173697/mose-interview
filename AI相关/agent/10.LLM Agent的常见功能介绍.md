## LLM Agent 的常见功能介绍

### 1. 核心功能全景

LLM Agent 的能力围绕"想清楚、做到、记得住、能纠错"展开：

| 功能 | 作用 |
| --- | --- |
| 规划（Planning） | 拆解任务、规划执行路径 |
| 工具调用（Tool Use） | 调用外部 API/代码扩展能力 |
| 记忆管理（Memory） | 短期上下文 + 长期经验存取 |
| 多步推理（Multi-step Reasoning） | 跨多步逐步逼近答案 |
| 自我反思（Reflection） | 评估自身输出并改进 |
| 多 Agent 协作 | 多角色分工合作 |
| 自我修正/重试 | 失败后自动换方案重试 |

### 2. 规划（Planning）

把复杂目标拆成可执行子任务：

| 子功能 | 说明 |
| --- | --- |
| 任务拆解 | 大目标→子任务列表 |
| ReAct | 边推理边行动，见 [[11.Agent智能体的核心工作流程]] |
| Plan-and-Execute | 先整体规划再执行 |
| 思维树（ToT） | 多分支探索+回溯 |

### 3. 工具调用（Tool Use）

运行时按需选择并调用工具（动态 API 调用见 [[13.LLM Agent动态API调用的实现方式]]）：

- 信息获取：搜索、RAG、数据库
- 计算：代码执行、代码解释器
- 外部动作：发邮件、调业务系统

### 4. 记忆管理（Memory）

| 能力 | 说明 |
| --- | --- |
| 短期记忆 | 维护当前对话/任务上下文 |
| 长期记忆 | 跨会话存取经验、用户偏好（见 [[12.LLM Agent长期记忆能力的实现方法]]） |
| 记忆检索 | 按相关性/时间/重要性召回相关记忆注入上下文 |

### 5. 多步推理（Multi-step Reasoning）

复杂问题一次答不出，Agent 逐步推进：
- 每步基于前序观察继续推理
- 中间结果作为后续步骤输入
- 典型：CoT、ReAct 循环

### 6. 自我反思（Reflection）

Agent 评估自己的输出质量并迭代改进：

```
生成初版答案 → 自评（是否准确/完整/符合要求）→ 发现不足 → 修正 → 输出
```

价值：减少单次生成错误，提升复杂任务质量。代表：Reflexion、Self-Refine。

### 7. 多 Agent 协作

多个 Agent 分工合作完成复杂任务：

| 模式 | 说明 |
| --- | --- |
| 角色分工 | 规划者/执行者/审查者各司其职 |
| 辩论 | 多 Agent 观点对抗，收敛出更优答案 |
| 层级 | 主 Agent 拆任务，子 Agent 执行 |

### 8. 自我修正/重试

| 场景 | 处理 |
| --- | --- |
| 工具调用失败 | 错误作为 Observation 回填，模型修正参数重试 |
| 答案不达标 | 反思后重新规划 |
| 走入死胡同 | 回溯换路径 |

### 9. 一句话总结

LLM Agent 的核心功能 = **规划（拆任务）+ 工具调用（做事）+ 记忆（存经验）+ 多步推理（逐步逼近）+ 自我反思（改进）+ 多 Agent 协作（分工）+ 自我修正（纠错）**，这些能力组合让 Agent 能自主完成复杂多步任务。
