## AI Agent 的定义及与直接调用大模型 API 问答的本质区别

> 原题标注"OpenClaw 前置"为教学标记，本篇讲通用概念，不涉及具体框架。

### 1. 各自是什么

- **直接调用大模型 API 问答**：把用户问题塞进 Prompt，调一次 LLM，拿回回答。单轮、无状态、无自主性。
- **AI Agent**：以 LLM 为大脑，能**自主规划、调用工具、维护记忆、多步执行、反思修正**，完成复杂任务的系统。

### 2. 本质区别

| 维度 | 直接调 API 问答 | AI Agent |
| --- | --- | --- |
| 交互轮次 | 单轮一问一答 | 多步自主循环 |
| 状态 | 无状态（每次独立） | 有记忆与状态，跨步延续 |
| 自主性 | 无，用户驱动每步 | 高，自己规划下一步 |
| 工具 | 无 | 可调用搜索/代码/数据库/API 等 |
| 记忆 | 无 | 短期上下文 + 长期记忆 |
| 复杂任务 | 只能答"知道的知识" | 能完成"需要多步+外部信息+操作"的任务 |
| 可控性 | 高（就是一次调用） | 低（自主循环，需防跑偏/死循环） |
| 成本 | 低 | 高（多轮+工具+长上下文） |

### 3. 一个例子说清区别

问"帮我查这家公司最新财报并算出同比增长率"：

- **直接调 API**：模型只能凭训练知识答，可能过时、可能编数字，算不了实时数据。
- **Agent**：规划→调搜索找财报→调工具读 PDF/表格→提取数字→调代码计算→输出带引用的结果。

差别在于 Agent 能**动起来**：获取外部信息、执行计算、多步达成。

### 4. 何时用 API，何时用 Agent

| 场景 | 选择 |
| --- | --- |
| 知识已在模型能力内、单轮能答 | 直接调 API，省成本 |
| 需要实时信息/外部数据 | Agent（要联网/查库） |
| 需要多步推理+工具+计算 | Agent |
| 需要跨轮记忆的复杂任务 | Agent |
| 对成本/延迟敏感的简单问答 | API |

### 5. 一句话总结

直接调 API 是**单轮无状态的知识问答**，Agent 是**多步自主、有记忆、能调用工具的任务执行系统**；本质区别在自主性、状态、工具与复杂任务能力——简单问答用 API，需要"动起来"的多步任务用 Agent。Agent 定义与传统 AI 系统的区别见 [[8.大模型Agent的定义及与传统AI系统的区别]]，架构见 [[9.LLM Agent的基本架构组成]]。
